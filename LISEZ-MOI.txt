PIXEL ARCADE — VERSION WEB / APPLICATION

Cette version est prête pour un hébergement statique (GitHub Pages, Netlify, Cloudflare Pages, etc.).

1. Envoyez TOUS les fichiers de ce dossier sur votre hébergeur.
2. La page d'accueil doit être index.html.
3. Ouvrez l'adresse HTTPS du site dans Chrome.
4. Chrome pourra alors proposer « Installer » lorsque les conditions PWA sont réunies.
5. L'installation ouvre Pixel Arcade comme une application, sans terminal ni mode développeur.

Ne séparez pas les fichiers : index.html, manifest, service worker et les deux icônes doivent rester accessibles à la racine du site.
